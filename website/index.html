05

Built, Broken, Fixed

During hardening, three serious bugs were found by execution, reproduced, root-caused, and fixed. Each now has regression coverage. This is the honest debugging timeline.

BUG 01

Silent Data Loss

critical 
multiple inserts
      ↓
same page repeatedly reinitialized
      ↓
previous records disappeared
root cause
Insert used the on-disk page count to determine whether a page was new — but dirty pages had not yet been flushed, so mid-session every insert looked like the first one on that page and re-ran the initializer.
fix
Track initialized pages in memory instead of trusting the file size.
result
Added regression coverage for multiple inserts in a single session — every record must survive.
BUG 02

Buffer Pool Crash

critical 
3 frames available
      ↓
request 4th distinct page
      ↓
no eviction policy
      ↓
program terminated
root cause
The pool had no replacement policy: a fourth distinct page with all frames occupied called exit(1). Any database larger than three pages was unreadable.
fix
Added round-robin eviction with dirty write-back.
result
Databases of any size are now readable; eviction and write-back are covered by buffer pool unit tests.
BUG 03

CLI Infinite Loop

major 
invalid input
      ↓
std::cin enters fail state
      ↓
input never recovered
      ↓
menu printed indefinitely
root cause
A non-numeric cin >> int leaves the stream in a fail state that was never cleared, so every later read failed instantly.
fix
Added input validation and fail-state recovery (cin.clear() + draining the bad line).
result
Non-numeric menu input is rejected and re-prompted; the loop can no longer spin.

08

Known Limitations

Scoped, documented, and deliberate — v1 trades optimality for clarity. These are stated in the README too, not hidden.

  • Round-robin eviction instead of LRU
  • No page compaction — deleted record bytes are never reclaimed
  • Fixed-size records — one 8-byte record type per database
  • Single-threaded — no concurrency control
  • No WAL / fsync — flush reaches the OS cache only
  • Raw-struct on-disk format — same-endianness assumption
  • No free-space map — inserts append to the current page
